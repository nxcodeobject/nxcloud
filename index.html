Kenapa nxcloud?

Dibangun dari pengalaman nyata — bukan teori.

Zero dependency runtime

100% JavaScript murni. Tidak ada npm install, tidak ada node_modules. CLI jalan langsung begitu clone.

Single executable

npm run build:exe menghasilkan nxcloud.exe standalone (Node SEA). Distribusi cukup 1 file + cloudflared.

Tahan banting

Tunnel tetap jalan meski cloudflared login rusak (bug upstream). DNS record dibuat via REST API Cloudflare — jalur alternatif yang selamat.

Multi-domain, satu tunnel

Kelola banyak hostname → banyak service lokal dari satu tunnel. nxcloud route add blog 3000 — CNAME + ingress otomatis.

Mini process manager

PID management, health check, graceful shutdown, stop/restart dari CLI. Server yang mengelola dirinya sendiri.

Secure by default

Bind ke 127.0.0.1, bukan 0.0.0.0. Satu-satunya pintu ke internet adalah tunnel yang kamu kontrol.

Cara kerjanya

Traffic mengalir dari internet ke PC kamu lewat jalur terenkripsi Cloudflare.

Tidak ada port yang dibuka di router. cloudflared membuat koneksi outbound ke Cloudflare — router, firewall, dan CGNAT tidak jadi masalah.

Mulai dalam 2 menit

Node.js 18+ dan cloudflared. Itu saja.

1

Install cloudflared

# Windows: download dari GitHub Cloudflare,
# atau taruh manual di .tools/cloudflared.exe

# Debian/Ubuntu
curl -L --output cloudflared.deb https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb
sudo dpkg -i cloudflared.deb
2

Clone & jalankan

git clone https://github.com/iyanrsaleh/nxcloud.git
cd nxcloud
node bin/nxcloud.js start
3

Hubungkan domain kamu

nxcloud config set cloudflare.apiToken <token>
nxcloud route add app 3000
# → https://app.domainkamu.id siap dipakai
